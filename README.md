个人维护的 FreshRSS 分支，clone 自 1.24.2，配合插件，多了以下功能：

- 快速搜索，>=3 字符走 fts5 快速搜索，<3 就退回官方的 LIKE 搜索
- 自定义 icon 图标，同时 icon 图标一旦保存，将不在进行更改，避免有时候网络不好导致变成原始的图标
- 所有源在读进时自动进行 Pangu Format，写入 feed 内容
- MathJax 公式渲染
- Gemini 一键总结 feed 内容
- 对 feed 内容进行高亮和保存
- 对 feed 排序增加发布日期逆序排列
- 增加全局和 regex 搜索
- 点击图片进行图片瀑布流浏览
- 未读情况下，点击加载更多自动将已有标记为已读
- 禁用拓展设置页的 GitHub 加载，速度加快
- 相同链接的文章，一旦读过一篇，其余自动标为已读
